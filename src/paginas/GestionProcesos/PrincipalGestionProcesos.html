Gestión de Procesos en Sistemas Operativos

Control eficiente de las tareas que permiten que un sistema funcione sin interrupciones.

Conceptos Clave en la Gestión de Procesos

¿Qué es un Proceso?

Un proceso es un programa en ejecución que necesita recursos del sistema como CPU, memoria y E/S para funcionar.

Ciclo de Vida del Proceso

  • Nuevo: Creado pero no iniciado.
  • Listo: Esperando uso de CPU.
  • En ejecución: Usando CPU.
  • Bloqueado: Espera un recurso.
  • Terminado: Finalizado.

Tipos de Procesos

  • Independientes: No dependen de otros procesos.
  • Interdependientes: Comparten datos o recursos.
  • Usuario: Iniciados por el usuario.
  • Sistema: Parte del funcionamiento del SO.
  • Primer plano: Visibles al usuario.
  • Segundo plano: Invisibles al usuario.

Creación y Eliminación

Los procesos se crean mediante llamadas al sistema como fork() o CreateProcess() y se eliminan al finalizar o mediante intervención del sistema.

Jerarquía de Procesos

El sistema mantiene relaciones padre-hijo entre procesos para controlar su ejecución y dependencias.

Asignación de Recursos

  • CPU: El planificador decide el orden de ejecución.
  • Memoria: Se gestiona mediante segmentación o paginación.
  • E/S: Para acceso a discos, red, etc.

Monitorización

Herramientas como ps, top o el Administrador de Tareas permiten observar procesos activos.

Conclusión

Comprender la gestión de procesos mejora el rendimiento, la estabilidad y el control del sistema operativo.
